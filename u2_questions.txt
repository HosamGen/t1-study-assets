Part 2 (U2 Attribution) questions: 100 in total, one block per question, sorted by id.

HOW TO BUILD EACH QUESTION (one page per question):
1. Text block with the TEXT, copied exactly (everything between the two lines of -----).
2. Label "Before" + Before image, label "After" + After image (side by side if the builder allows).
3. One answer question PER BOX, titled "[id] Box N" (e.g. "[h294] Box 1"). Use a dropdown if the builder has one,
   otherwise single-select (exactly one answer). Options = that question's list below, exactly as written and in that
   order. The letters and their order differ between questions. Required; nothing pre-selected; no option randomization.

INSTRUCTIONS PAGE TEXT (one text page before the first question; copy exactly):
-----
How to answer: "Which objective does each box serve?"

You will see two photos of the same place: BEFORE the project and AFTER it, plus a list of the project's objectives labelled with letters. For every numbered box, choose one letter:
- the objective that the change in that box serves;
- "Not a documented objective" if the box changed but the change serves none of the listed objectives;
- "No change here" if the box did not change.

A letter can be used for several boxes, and some letters may not be used at all. The letters are in a different order in every question, so read the list each time.

Example (made up):
Objectives: A. Add greenery to the square. B. No change here. C. Improve lighting at night. D. Not a documented objective.
Box 1: new trees planted. Answer A.
Box 2: new street lamps. Answer C.
Box 3: the building looks the same. Answer B.
Box 4: a new advertising billboard that serves none of the objectives. Answer D.
