HOW TO BUILD EACH QUESTION (one page per question):
1. Text block with the TEXT, copied exactly (everything between the two lines of -----).
2. Label "Before" + the Before image. There is NO After image in this part.
3. ONE answer question, type MULTI-SELECT (select all that apply), titled "[id] Your answer: select all boxes that apply (at least one)".
   Options = Box 1 ... Box N as listed in the block, in that order. NO "None" option. Required; minimum 1 selection if the
   builder has that setting; nothing pre-selected; no option randomization.

INSTRUCTIONS PAGE TEXT (one text page before the first question; copy exactly):

How to answer: "Which boxes would the project have to change?"

You will see only the BEFORE photo of a place; the result of the project is not shown. The brief states one objective.

Select every box that the project would have to change to achieve that objective. Do not select boxes that this objective does not require changing, even if they could be improved in other ways. Select at least one box.

Example (made up):
Objective: "Give pedestrians more shade while walking."
Box 1 (a wide sidewalk with no trees): needs trees or awnings. Select it.
Box 2 (the upper floors of a building): no change needed for shade at street level. Do not select it.
Box 3 (the road surface): not needed for shade. Do not select it.
Answer: Box 1.
